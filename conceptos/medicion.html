📏 Medición

Aprende los conceptos fundamentales de medición necesarios para comprender cómo medir, verificar y diagnosticar magnitudes eléctricas y mecánicas en la industria y la automatización.

📏 ¿Qué es la medición?

La medición es el proceso de determinar el valor de una magnitud física mediante instrumentos y técnicas de comparación con un patrón o unidad de referencia.

En Electromecánica Industrial, la medición es fundamental para verificar el funcionamiento de motores, circuitos, tableros, sistemas de control, instalaciones eléctricas y sistemas de automatización.

Un sistema de medición puede utilizar instrumentos como multímetros, amperímetros, voltímetros, óhmetros, pinzas amperimétricas, termómetros y manómetros.

📚 Conceptos fundamentales

🛠️

1. Instrumentos de medición

Dispositivos utilizados para medir magnitudes físicas como voltaje, corriente, resistencia, presión y temperatura.

Ejemplos: multímetro, manómetro, termómetro.

📐

2. Unidades de medida

Cantidades patrón que se utilizan como referencia para expresar el valor de una magnitud física.

Norma común: SI

⚡

3. Medición de voltaje

Proceso de medir la diferencia de potencial entre dos puntos de un circuito mediante un voltímetro.

🔌

4. Medición de corriente

Proceso de medir la intensidad de corriente que circula por un circuito mediante un amperímetro.

Ω

5. Medición de resistencia

Proceso de medir la resistencia eléctrica de un componente o circuito mediante un óhmetro.

🧲

6. Medición de presión

Proceso de medir la presión de un fluido o gas mediante un manómetro o sensor de presión.

🌡️

7. Medición de temperatura

Proceso de medir la temperatura de un sistema mediante termómetros o sensores de temperatura.

💧

8. Medición de caudal

Proceso de medir la cantidad de fluido que circula por una tubería o canal en un tiempo determinado.

🎯

9. Precisión

Grado de exactitud con el que un instrumento de medición indica el valor real de la magnitud medida.

⚠️

10. Error de medición

Diferencia entre el valor medido por un instrumento y el valor real de la magnitud.

🧮 Ejemplo de aplicación

Supongamos que necesitamos verificar el funcionamiento de un motor eléctrico dentro de un sistema industrial.

Primero, un voltímetro mide el voltaje que llega al motor para verificar que sea el adecuado.

Después, una pinza amperimétrica mide la corriente que consume el motor sin interrumpir el circuito.

Posteriormente, un óhmetro verifica la resistencia de los bobinados del motor.

También se pueden medir la presión, la temperatura y el caudal de los sistemas hidráulicos y neumáticos.

De esta manera, la medición permite diagnosticar el estado del motor y del sistema.

🧠 ¿Cómo se relacionan estos conceptos?

🛠️ Instrumentos: permiten medir las magnitudes físicas.

📐 Unidades: sirven de referencia para expresar el valor.

⚡ Voltaje: se mide con un voltímetro.

🔌 Corriente: se mide con un amperímetro.

Ω Resistencia: se mide con un óhmetro.

🧲 Presión: se mide con un manómetro.

🌡️ Temperatura: se mide con un termómetro.

🎯 Precisión: indica la exactitud de la medición.

⚠️ Error: diferencia entre el valor medido y el valor real.
