➖ Diagrama unifilar

Representación simplificada de un sistema eléctrico que utiliza una sola línea para mostrar las conexiones.

➖ ¿Qué es un diagrama unifilar?

El diagrama unifilar es una representación simplificada de un sistema eléctrico que utiliza una sola línea para representar un circuito trifásico o monofásico, mostrando las conexiones entre los componentes principales.

En Electromecánica Industrial, el diagrama unifilar se utiliza en tableros de distribución, subestaciones, arrancadores de motores y sistemas de alimentación, proporcionando una visión general del sistema.

Se elabora según la norma IEC, indicando los componentes principales, sus valores y las protecciones del sistema.

🧬 Tipos de diagramas unifilares

De distribución: representan el sistema de alimentación de una planta desde la acometida hasta las cargas.

De tablero: representan la distribución interna de un tablero de control o fuerza.

De arranque: representan el sistema de alimentación de un motor con sus protecciones.

De subestación: representan la alimentación desde la red hasta los transformadores y tableros.

🧮 Ejemplo práctico

1. Se tiene un tablero principal que alimenta tres motores trifásicos.

2. El diagrama unifilar muestra una sola línea desde la acometida hasta el tablero.

3. Se indican el interruptor principal, las protecciones y los arrancadores de cada motor.

4. Cada ramal se representa con una línea y sus componentes asociados.

5. El diagrama permite ver de un vistazo toda la distribución y las protecciones del sistema.

🏭 Aplicación en electromecánica

El diagrama unifilar se utiliza en tableros de distribución, subestaciones, arrancadores de motores, sistemas de alimentación y diseño de instalaciones industriales.

⚠️ Errores comunes

Confundir unifilar con esquemático: el unifilar es simplificado y el esquemático es detallado.

Omitir las protecciones: el diagrama debe indicar los interruptores y protecciones del sistema.

No indicar las secciones de los cables: dificulta la verificación de la capacidad del sistema.

No respetar la norma IEC: los símbolos y designaciones deben ser normalizados para su interpretación.

📌 Resumen

El diagrama unifilar representa de forma simplificada un sistema eléctrico mediante una sola línea. Se utiliza en tableros, subestaciones y arrancadores, indicando los componentes y protecciones según la norma IEC.
