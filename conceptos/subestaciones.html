⚡ Subestaciones eléctricas

Aprende los conceptos fundamentales de las subestaciones eléctricas y de los principales equipos utilizados para transformar, controlar, proteger y distribuir energía.va

⚡ ¿Qué es una subestación eléctrica?

Una subestación eléctrica es una instalación que forma parte de un sistema eléctrico y que permite realizar funciones como transformación, maniobra, protección y distribución de energía.va

En Electromecánica Industrial, conocer sus componentes permite comprender cómo se transporta y distribuye la energía eléctrica hacia diferentes instalaciones y equipos.va

Las subestaciones pueden incorporar transformadores, interruptores, seccionadores, barras, sistemas de protección, medición y puesta a tierra.va

📚 Conceptos fundamentales

⚡

1. Subestación eléctrica

Instalación que permite realizar funciones de transformación, maniobra, protección y distribución de energía eléctrica.va

🔄

2. Transformador

Equipo eléctrico utilizado para modificar los niveles de tensión mediante inducción electromagnética.va

🔌

3. Interruptor de potencia

Dispositivo utilizado para abrir o cerrar un circuito y, según su diseño, interrumpir corrientes de falla.va

⛓️

4. Seccionador

Dispositivo utilizado para proporcionar aislamiento visible de una parte del circuito cuando las condiciones de operación lo permiten.va

⚡

5. Pararrayos

Dispositivo utilizado para limitar sobretensiones y proteger equipos eléctricos.va

📊

6. Transformadores de instrumento

Equipos utilizados para adaptar magnitudes eléctricas a valores apropiados para medición y protección.va

〰️

7. Barras colectoras

Conductores principales utilizados para conectar y distribuir energía eléctrica dentro de una instalación.va

🌎

8. Sistema de puesta a tierra

Sistema destinado a proporcionar una conexión controlada con tierra para funciones de seguridad y operación.va

🛡️

9. Protección eléctrica

Conjunto de dispositivos y sistemas destinados a detectar y aislar condiciones anormales o fallas.va

🏭

10. Patio de maniobras

Área donde se encuentran equipos eléctricos utilizados para maniobrar, transformar, proteger y distribuir energía.va

🧮 Ejemplo de aplicación

Supongamos que una instalación industrial necesita recibir energía eléctrica desde una red de distribución.va

La energía llega a la subestación eléctrica.va

Un transformador puede modificar el nivel de tensión de acuerdo con las necesidades de la instalación.va

Los interruptores y sistemas de protección permiten controlar y proteger los circuitos.va

Las barras colectoras permiten distribuir la energía hacia diferentes circuitos.va

El sistema de puesta a tierra forma parte de las medidas de seguridad y funcionamiento de la instalación.va

🧠 ¿Cómo se relacionan estos conceptos?

⚡ Subestación: integra diferentes equipos eléctricos.va

🔄 Transformador: modifica el nivel de tensión.va

🔌 Interruptor: permite controlar e interrumpir circuitos.va

⛓️ Seccionador: proporciona aislamiento del circuito.va

⚡ Pararrayos: ayuda a proteger frente a sobretensiones.va

〰️ Barras: distribuyen energía dentro de la instalación.va

🌎 Puesta a tierra: forma parte de la seguridad eléctrica.va

🛡️ Protección: detecta y ayuda a aislar condiciones anormales.va
