📐 Unidades de medida

Cantidades patrón que se utilizan como referencia para expresar el valor de una magnitud física. Norma común: SI.

📐 ¿Qué son las unidades de medida?

Las unidades de medida son cantidades patrón que se utilizan como referencia para expresar el valor de una magnitud física, como el metro para la longitud, el kilogramo para la masa y el segundo para el tiempo.

En Electromecánica Industrial, el uso de unidades normalizadas es fundamental para garantizar la comunicación universal y la precisión en las mediciones, los cálculos y el dimensionamiento de los sistemas.

La norma común es el Sistema Internacional de Unidades (SI), según la norma IEC.

🧬 Tipos de unidades de medida

Unidades eléctricas: el voltio (V) para el voltaje, el amperio (A) para la corriente y el ohmio (Ω) para la resistencia.

Unidades de presión: el pascal (Pa), el bar y el kilogramo por centímetro cuadrado (kg/cm²).

Unidades de temperatura: el grado Celsius (°C), el kelvin (K) y el grado Fahrenheit (°F).

Unidades de caudal: el litro por segundo (L/s) y el metro cúbico por hora (m³/h).

🧮 Ejemplo práctico

1. Se tiene un motor trifásico que debe dimensionarse su protección.

2. La corriente nominal del motor se expresa en amperios(A).

3. El voltaje de la red se expresa en voltios(V).

4. La potencia del motor se expresa en kilovatios(kW).

5. Todas las unidades siguen el Sistema Internacional (SI).

🏭 Aplicación en electromecánica

Las unidades de medida se aplican en el dimensionamiento de motores, conductores, protecciones y tuberías, así como en los cálculos de potencia, presión, temperatura y caudal de los sistemas industriales.

⚠️ Errores comunes

Confundir unidades: mezclar voltios y amperios, o bares y pascales, provoca errores de cálculo.

No convertir las unidades: es necesario convertir las unidades antes de realizar los cálculos.

No respetar el SI: el Sistema Internacional es la norma común para las mediciones.

No verificar los prefijos: confundir kilo, mega y mili provoca errores de magnitud.
