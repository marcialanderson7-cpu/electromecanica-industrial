⚡ Arco eléctrico

El arco eléctrico es una descarga eléctrica que genera el calor necesario para fundir el material durante determinados procesos de soldadura.y

⚡ ¿Qué es el arco eléctrico?

El arco eléctrico es una descarga eléctrica continua que se produce entre dos conductores, normalmente entre el electrodo y la pieza de trabajo. Esta descarga genera una temperatura muy alta, suficiente para fundir el metal.

En la soldadura por arco, el calor del arco funde el material base y, en muchos casos, el material de aporte, formando así la unión entre las piezas.

El arco eléctrico es la base de los procesos de soldadura más comunes, como SMAW, MIG y TIG.

 🛡️

 〰️

Cordón

Depósito de material fundido que forma la unión entre las piezas.

✨ Características principales

  • Genera calor intenso: el arco alcanza temperaturas muy altas, suficientes para fundir metales.
  • Es una descarga eléctrica: se produce entre dos conductores, normalmente electrodo y pieza.
  • Emite luz intensa: el arco produce una luz muy brillante que requiere protección ocular.
  • Es la base de varios procesos: SMAW, MIG y TIG usan arco eléctrico.

⚙️ ¿Cómo se produce el arco?

El arco eléctrico se produce de la siguiente manera:

  • 1. Contacto: el electrodo se acerca a la pieza de trabajo hasta hacer contacto.
  • 2. Separación: el electrodo se separa ligeramente de la pieza, creando un pequeño espacio.
  • 3. Descarga: la corriente salta através del espacio, ionizando el aire y creando el arco.
  • 4. Mantenimiento: el arco se mantiene mientras el electrodo se desplaza a lo largo de la unión.

⚡ Ejemplo práctico

1-Imagina un soldador que va a unir dos placas de acero con un proceso SMAW. Al acercar el electrodo a la placa y separarlo, se forma un arco eléctrico brillante.

2-El calor del arco funde el metal de las placas y el revestimiento del electrodo, formando el cordón de soldadura que une las placas.

3-El soldador debe usar un casco con filtro oscuro para proteger sus ojos de la luz intensa del arco.

🏭 Aplicación en electromecánica

El arco eléctrico es fundamental en:

  • Soldadura SMAW: el electrodo revestido establece el arco y aporta material.
  • Soldadura MIG: el arco se produce entre el alambre continuo y la pieza.
  • Soldadura TIG: el arco se produce entre un electrodo de tungsteno y la pieza.
  • Corte por arco: algunos procesos usan el arco para cortar metal.

⚠️ Errores comunes

  • Mirar el arco sin protección ocular. La luz del arco puede causar daños graves e permanentes a la vista.
  • Pensar que el arco es igual en todos los procesos. La intensidad y características varían según el proceso y la corriente.
  • Creer que el arco solo funde el material de aporte. También funde el material base de las piezas.
