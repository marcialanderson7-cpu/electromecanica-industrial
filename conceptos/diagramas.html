📐 Diagramas eléctricos

Aprende los conceptos fundamentales de los diagramas eléctricos necesarios para interpretar, diseñar y mantener sistemas eléctricos en la industria y la automatización.

📐 ¿Qué son los diagramas eléctricos?

Los diagramas eléctricos son representaciones gráficas de un circuito o sistema eléctrico, que utilizan símbolos normalizados para mostrar la conexión y el funcionamiento de sus componentes.

En Electromecánica Industrial, los diagramas eléctricos son fundamentales para comprender el funcionamiento de motores, tableros, sistemas de control, PLC, instalaciones eléctricas y sistemas de automatización.

Un diagrama eléctrico puede representar componentes como fuentes, conductores, interruptores, protecciones, contactores, relés, motores y dispositivos de control.

📚 Conceptos fundamentales

🔗

1. Conexiones eléctricas

Formas de unir eléctricamente los componentes de un circuito para que la corriente fluya correctamente.

🤝

2. Contactos eléctricos

Dispositivos que abren o cierran un circuito para controlar el paso de la corriente eléctrica.

📐

3. Diagrama esquemático

Representación de un circuito mediante símbolos normalizados que muestra las conexiones eléctricas de sus componentes.

➖

4. Diagrama unifilar

Representación simplificada de un sistema eléctrico que utiliza una sola línea para mostrar las conexiones.

🎛️

5. Diagramas de control

Representaciones que muestran la parte del circuito que gobierna el funcionamiento de los dispositivos de potencia o de carga.

⚡

6. Diagramas de fuerza

Representaciones que muestran la parte del circuito que maneja la energía principal que alimenta motores y cargas pesadas.

🧠

7. Interpretación de diagramas

Proceso de leer y comprender la información que presentan los diagramas eléctricos para entender el funcionamiento del sistema.

🔘

8. Interruptores

Dispositivos de maniobra que abren o cierran un circuito eléctrico para controlar el paso de la corriente.

🔁

9. Relés y contactores

Dispositivos electromagnéticos que controlan circuitos de potencia a partir de señales de control de baja potencia.

🔣

10. Símbolos eléctricos

Representaciones gráficas normalizadas utilizadas para identificar los componentes de un circuito eléctrico.

Norma común: IEC

🧮 Ejemplo de aplicación

Supongamos que necesitamos arrancar un motor eléctrico dentro de un sistema de control industrial.

Primero, un diagrama de fuerza muestra cómo se alimenta el motor con la energía principal.

Después, un diagrama de control muestra cómo los contadores y relés gobiernan el arranque del motor.

Posteriormente, los interruptores y contactos permiten abrir y cerrar el circuito de control.

El diagrama esquemático representa todo el circuito mediante símbolos normalizados.

De esta manera, la interpretación de diagramas permite comprender y mantener el sistema.

🧠 ¿Cómo se relacionan estos conceptos?

🔗 Conexiones: unen los componentes del circuito.

🤝 Contactos: abren o cierran el circuito.

📐 Esquemático: representa el circuito con símbolos.

➖ Unifilar: muestra una vista simplificada del sistema.

🎛️ Control: gobierna el funcionamiento de los dispositivos.

⚡ Fuerza: maneja la energía principal del sistema.

🔘 Interruptores: controlan el paso de la corriente.

🔁 Relés y contactores: controlan circuitos de potencia.

🔣 Símbolos: identifican los componentes del circuito.
