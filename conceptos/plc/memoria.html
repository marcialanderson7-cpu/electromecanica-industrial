💾 Memoria

Permite almacenar información utilizada por el programa y el funcionamiento del controlador.

💾 ¿Qué es la memoria?

La memoria es el componente del PLC que permite almacenar información utilizada por el programa y el funcionamiento del controlador.

Almacena el programa de control, los datos del proceso y las variables internas.

Su objetivo es conservar la información necesaria para el funcionamiento del sistema.

📚 Conceptos fundamentales

🧠

PLC

Controlador lógico programable que automatiza máquinas y procesos.

⚙️

CPU

Unidad que ejecuta el programa de control.

📐

Lenguaje Ladder

Representa la lógica de control mediante un diagrama de escalera.

🔄

Ciclo de escaneo

Secuencia repetitiva en la que el PLC procesa la información.

📥

Entradas digitales

Reciben señales de los dispositivos del proceso.

🗂️ Tipos de memoria

  • RAM: almacena datos de forma temporal.
  • ROM: almacena información de forma permanente.
  • EEPROM: conserva el programa sin alimentación.
  • De respaldo: mantiene los datos con batería.

La elección del tipo depende de la aplicación y de la información a conservar.

🧮 Ejemplo práctico

1. El programa se almacena en la memoria.

2. La CPU lee el programa almacenado.

3. Los datos del proceso se guardan.

4. La información se conserva con respaldo.

🏭 Aplicación en electromecánica

La memoria se aplica en:

  • Programas: almacena el programa de control.
  • Datos: guarda los valores del proceso.
  • Variables: conserva los estados internos.
  • Respaldo: mantiene la información sin alimentación.

⚠️ Errores comunes

  • Confundir los tipos de memoria.
  • No respaldar el programa de control.
  • Ignorar la capacidad de la memoria.
  • No verificar la batería de respaldo.

📝 Ejercicios

1. ¿Qué es la memoria?

Es el componente que almacena información utilizada por el programa y el controlador.

2. ¿Cuál es su objetivo?

Conservar la información necesaria para el funcionamiento del sistema.

3. ¿Qué tipos de memoria existen?

RAM, ROM, EEPROM y de respaldo.

4. ¿Por qué es importante el respaldo?

Para conservar el programa y los datos sin alimentación.

📋 Resumen

La memoria almacena el programa y los datos del controlador.

Puede ser RAM, ROM, EEPROM o de respaldo, según la aplicación.
